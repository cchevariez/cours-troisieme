# AP - Calcul littéral

**Objectif :** revoir le développement et surtout la réduction des expressions littérales, à raison d'un exercice court chaque jour pendant 10 jours. Compte 10 à 15 minutes par jour.

> [!methode] Méthode
> **Développer**, c'est distribuer chaque terme du facteur sur chaque terme de la parenthèse. **Réduire**, c'est regrouper les termes de même nature (même lettre, même puissance).

## Jour 1 — Réduire une expression

> [!exemple] Exemple
> $$E = 3x + 5 - x + 2$$
>
> $$E = (3x - x) + (5 + 2)$$
>
> $$E = 2x + 7$$

> [!exercice] Jour 1 (10-15 min)
> Réduire :
> - $A = 4x + 3 - 2x + 5$
> - $B = -3x + 7 + 5x - 2$
> - $C = 6 - 2x + 3 - x$

> [!correction]- Correction — Jour 1
> - $$A = 4x + 3 - 2x + 5$$
> - $$A = (4x - 2x) + (3 + 5)$$
> - $$A = 2x + 8$$
> - $$B = -3x + 7 + 5x - 2$$
> - $$B = (-3x + 5x) + (7 - 2)$$
> - $$B = 2x + 5$$
> - $$C = 6 - 2x + 3 - x$$
> - $$C = (-2x - x) + (6 + 3)$$
> - $$C = -3x + 9$$

## Jour 2 — Réduire avec plusieurs types de termes

> [!exemple] Exemple
> $$E = 2x^2 + 3x - x^2 + 5x - 4$$
>
> $$E = (2x^2 - x^2) + (3x + 5x) - 4$$
>
> $$E = x^2 + 8x - 4$$
>
> On ne regroupe que les termes de même nature : les $x^2$ entre eux, les $x$ entre eux, les nombres seuls entre eux.

> [!exercice] Jour 2 (10-15 min)
> Réduire :
> - $A = 3x^2 + 4x - x^2 + 2x - 5$
> - $B = 5x - 2x^2 + 3 + x^2 - x$
> - $C = x^2 + 7 - 3x + 2x^2 - 4$

> [!correction]- Correction — Jour 2
> - $$A = 3x^2 + 4x - x^2 + 2x - 5$$
> - $$A = (3x^2 - x^2) + (4x + 2x) - 5$$
> - $$A = 2x^2 + 6x - 5$$
> - $$B = 5x - 2x^2 + 3 + x^2 - x$$
> - $$B = (-2x^2 + x^2) + (5x - x) + 3$$
> - $$B = -x^2 + 4x + 3$$
> - $$C = x^2 + 7 - 3x + 2x^2 - 4$$
> - $$C = (x^2 + 2x^2) - 3x + (7 - 4)$$
> - $$C = 3x^2 - 3x + 3$$

## Jour 3 — Développer $k(a+b)$, $k$ positif

> [!exemple] Exemple
> $$E = 3(x + 4)$$
>
> $$E = 3 \times x + 3 \times 4$$
>
> $$E = 3x + 12$$

> [!exercice] Jour 3 (10-15 min)
> Développer :
> - $A = 5(x + 2)$
> - $B = 2x(x + 3)$
> - $C = 4(2x + 1)$

> [!correction]- Correction — Jour 3
> - $$A = 5(x + 2)$$
> - $$A = 5 \times x + 5 \times 2$$
> - $$A = 5x + 10$$
> - $$B = 2x(x + 3)$$
> - $$B = 2x \times x + 2x \times 3$$
> - $$B = 2x^2 + 6x$$
> - $$C = 4(2x + 1)$$
> - $$C = 4 \times 2x + 4 \times 1$$
> - $$C = 8x + 4$$

## Jour 4 — Développer $k(a+b)$, $k$ négatif

> [!exemple] Exemple
> $$E = -3(x + 4)$$
>
> $$E = -3 \times x + (-3) \times 4$$
>
> $$E = -3x - 12$$
>
> Le signe négatif du facteur se distribue sur chaque terme.

> [!exercice] Jour 4 (10-15 min)
> Développer :
> - $A = -2(x + 5)$
> - $B = -4(2x + 3)$
> - $C = -x(x + 6)$

> [!correction]- Correction — Jour 4
> - $$A = -2(x + 5)$$
> - $$A = -2 \times x + (-2) \times 5$$
> - $$A = -2x - 10$$
> - $$B = -4(2x + 3)$$
> - $$B = -4 \times 2x + (-4) \times 3$$
> - $$B = -8x - 12$$
> - $$C = -x(x + 6)$$
> - $$C = -x \times x + (-x) \times 6$$
> - $$C = -x^2 - 6x$$

## Jour 5 — Développer puis réduire

> [!exemple] Exemple
> $$E = 2(x + 3) + 4x$$
>
> $$E = 2x + 6 + 4x$$
>
> $$E = 6x + 6$$

> [!exercice] Jour 5 (10-15 min)
> Développer et réduire :
> - $A = 3(x + 5) - 2x$
> - $B = 4(x + 2) + 3x - 5$
> - $C = -2(x + 3) + 7x$

> [!correction]- Correction — Jour 5
> - $$A = 3(x + 5) - 2x$$
> - $$A = 3x + 15 - 2x$$
> - $$A = (3x - 2x) + 15$$
> - $$A = x + 15$$
> - $$B = 4(x + 2) + 3x - 5$$
> - $$B = 4x + 8 + 3x - 5$$
> - $$B = (4x + 3x) + (8 - 5)$$
> - $$B = 7x + 3$$
> - $$C = -2(x + 3) + 7x$$
> - $$C = -2x - 6 + 7x$$
> - $$C = (-2x + 7x) - 6$$
> - $$C = 5x - 6$$

## Jour 6 — Somme de deux produits

> [!exemple] Exemple
> $$E = 3(x + 2) + 2(x + 5)$$
>
> $$E = 3x + 6 + 2x + 10$$
>
> $$E = 5x + 16$$

> [!exercice] Jour 6 (10-15 min)
> Développer et réduire :
> - $A = 2(x + 4) + 3(x + 1)$
> - $B = 5(x + 3) + 2(x - 4)$
> - $C = 3(2x + 1) + 4(x + 2)$

> [!correction]- Correction — Jour 6
> - $$A = 2(x + 4) + 3(x + 1)$$
> - $$A = 2x + 8 + 3x + 3$$
> - $$A = (2x + 3x) + (8 + 3)$$
> - $$A = 5x + 11$$
> - $$B = 5(x + 3) + 2(x - 4)$$
> - $$B = 5x + 15 + 2x - 8$$
> - $$B = (5x + 2x) + (15 - 8)$$
> - $$B = 7x + 7$$
> - $$C = 3(2x + 1) + 4(x + 2)$$
> - $$C = 6x + 3 + 4x + 8$$
> - $$C = (6x + 4x) + (3 + 8)$$
> - $$C = 10x + 11$$

## Jour 7 — Produit de deux sommes

> [!exemple] Exemple
> $$E = (x + 2)(x + 5)$$
>
> $$E = x \times x + x \times 5 + 2 \times x + 2 \times 5$$
>
> $$E = x^2 + 5x + 2x + 10$$
>
> $$E = x^2 + 7x + 10$$
>
> Chaque terme de la première parenthèse multiplie chaque terme de la seconde.

> [!exercice] Jour 7 (10-15 min)
> Développer et réduire :
> - $A = (x + 3)(x + 4)$
> - $B = (x - 2)(x + 6)$
> - $C = (2x + 1)(x + 5)$

> [!correction]- Correction — Jour 7
> - $$A = (x + 3)(x + 4)$$
> - $$A = x \times x + x \times 4 + 3 \times x + 3 \times 4$$
> - $$A = x^2 + 4x + 3x + 12$$
> - $$A = x^2 + 7x + 12$$
> - $$B = (x - 2)(x + 6)$$
> - $$B = x \times x + x \times 6 - 2 \times x - 2 \times 6$$
> - $$B = x^2 + 6x - 2x - 12$$
> - $$B = x^2 + 4x - 12$$
> - $$C = (2x + 1)(x + 5)$$
> - $$C = 2x \times x + 2x \times 5 + 1 \times x + 1 \times 5$$
> - $$C = 2x^2 + 10x + x + 5$$
> - $$C = 2x^2 + 11x + 5$$

## Jour 8 — Le cas $-(a+b)$

> [!exemple] Exemple
> $$E = -(2x - 1)$$
>
> $$E = -2x + 1$$
>
> Une parenthèse précédée d'un signe « $-$ » seul revient à multiplier par $-1$ : chaque terme change de signe.

> [!exercice] Jour 8 (10-15 min)
> Développer et réduire :
> - $A = 7 - (x + 4)$
> - $B = 3(x + 1) - (2x - 5)$
> - $C = -(3x - 2) + 4x$

> [!correction]- Correction — Jour 8
> - $$A = 7 - (x + 4)$$
> - $$A = 7 - x - 4$$
> - $$A = -x + 3$$
> - $$B = 3(x + 1) - (2x - 5)$$
> - $$B = 3x + 3 - 2x + 5$$
> - $$B = (3x - 2x) + (3 + 5)$$
> - $$B = x + 8$$
> - $$C = -(3x - 2) + 4x$$
> - $$C = -3x + 2 + 4x$$
> - $$C = (-3x + 4x) + 2$$
> - $$C = x + 2$$

## Jour 9 — Consolidation

> [!exercice] Jour 9 (10-15 min)
> Développer et réduire :
> - $A = 4(x + 3) - 2(x - 1)$
> - $B = (x + 4)(x - 2) + 3x$
> - $C = -(2x + 3) + 5(x + 1)$

> [!correction]- Correction — Jour 9
> - $$A = 4(x + 3) - 2(x - 1)$$
> - $$A = 4x + 12 - 2x + 2$$
> - $$A = (4x - 2x) + (12 + 2)$$
> - $$A = 2x + 14$$
> - $$B = (x + 4)(x - 2) + 3x$$
> - $$B = x \times x - 2x + 4x - 8 + 3x$$
> - $$B = x^2 - 2x + 4x - 8 + 3x$$
> - $$B = x^2 + (-2x + 4x + 3x) - 8$$
> - $$B = x^2 + 5x - 8$$
> - $$C = -(2x + 3) + 5(x + 1)$$
> - $$C = -2x - 3 + 5x + 5$$
> - $$C = (-2x + 5x) + (-3 + 5)$$
> - $$C = 3x + 2$$

## Jour 10 — Bilan (type brevet, en autonomie)

> [!exercice] Jour 10 (10-15 min)
> Développer et réduire :
> - $A = 4(x + 3) - 6x$
> - $B = (x - 4)(2x + 3)$
> - $C = (3x - 1)(x + 2) - 5x$
> - $D = 6(2x - 1) - 3(x - 2)$

> [!correction]- Correction — Jour 10
> - $$A = 4(x + 3) - 6x$$
> - $$A = 4x + 12 - 6x$$
> - $$A = (4x - 6x) + 12$$
> - $$A = -2x + 12$$
> - $$B = (x - 4)(2x + 3)$$
> - $$B = x \times 2x + x \times 3 - 4 \times 2x - 4 \times 3$$
> - $$B = 2x^2 + 3x - 8x - 12$$
> - $$B = 2x^2 - 5x - 12$$
> - $$C = (3x - 1)(x + 2) - 5x$$
> - $$C = 3x \times x + 3x \times 2 - 1 \times x - 1 \times 2 - 5x$$
> - $$C = 3x^2 + 6x - x - 2 - 5x$$
> - $$C = 3x^2 + (6x - x - 5x) - 2$$
> - $$C = 3x^2 - 2$$
> - $$D = 6(2x - 1) - 3(x - 2)$$
> - $$D = 12x - 6 - 3x + 6$$
> - $$D = (12x - 3x) + (-6 + 6)$$
> - $$D = 9x$$
